# FTP Digital Plus - Tarjetas de Presentación Digitales

Demo de plataforma web para crear tarjetas de presentación digitales con 3 planes (Gratis, Básico, Pro).

## 🚀 Despliegue rápido en Vercel

Ver guía completa: [DEPLOY-VERCEL.md](./DEPLOY-VERCEL.md)

### Resumen:
1. Subir código a GitHub
2. En Vercel: Add New → Project → Seleccionar repo
3. Deploy (configuración automática)
4. ¡Listo!

## 🔑 Cuentas demo

- `demo@gratis.com` / `demo123` — Plan Gratis
- `demo@basico.com` / `demo123` — Plan Básico
- `demo@pro.com` / `demo123` — Plan Pro

## 🛠️ Desarrollo local

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## 📦 Tecnología

- Next.js 16 + TypeScript 5
- Tailwind CSS 4 + shadcn/ui
- Zustand (estado)
- Recharts (gráficas)
- Framer Motion (animaciones)
- qrcode.react (códigos QR)
